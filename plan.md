## Plan: Small Molecule & Peptide Inhibitor Docking Pipeline

### TL;DR
Add a new **`inhibitor_agent`** LangGraph node between `protein_agent` and `skeptic_agent` that:
1. Uses the RNA-binding site (from protein_agent's interface contact analysis) to define the docking pocket
2. Fetches/generates small molecule inhibitors and docks them into that pocket with **AutoDock Vina**
3. Generates peptide sequences via the LLM, builds 3D peptide structures, docks with **HDOCK** (protein-small protein mode)
4. Compares inhibitor poses with RNA binding modes
5. Feeds results into the skeptic agent for integrated critique

---

### Pipeline Architecture

**Current flow:** `pi → researcher → bioinfo → structural → md → protein → skeptic → [loop/end]`

**Target flow:** `pi → researcher → bioinfo → structural → md → protein → **inhibitor** → skeptic → [loop/end]`

The inhibitor_agent receives the state after protein_agent has produced:
- `binding_results` (RNA docking data with interface contacts)
- `target_pdb` (the protein target)
- Known RNA-binding pocket residue information from interface contact analysis

### Phase 1: New Core Modules (parallel with Phase 2)

#### Step 1.1: `core/small_molecule_prep.py` — Small molecule fetching and preparation
- **Source**: PubChem REST API (`https://pubchem.ncbi.nlm.nih.gov/rest/pug/`) — no extra dependencies
- **Approach**:
  - Search for compounds by target protein name or known RNA-binding inhibitors
  - Fetch top N compounds as SDF, convert with OpenBabel to PDB, then to PDBQT for Vina
  - Use OpenBabel `--gen3d` for 3D conformer generation if needed
- **Key functions**:
  - `fetch_pubchem_compounds(query: str, max_compounds: int)` → list of SMILES/PubChem CIDs
  - `prepare_small_molecule(smiles: str, output_dir: str)` → path to PDBQT
  - `fetch_known_rna_binding_inhibitors()` → curated list of known RNA-binding pocket inhibitors
- **Caching**: Cache by SMILES hash to avoid re-downloading

#### Step 1.2: `core/peptide_prep.py` — Peptide structure generation
- **Source**: Peptide sequences generated by the LLM (get_llm call in inhibitor_agent)
- **Structure generation**: Use **OpenBabel** `--gen3d` to build extended 3D peptide PDB from sequence
  - `obabel -:"ACDEFG" -opdb --gen3d -O peptide.pdb`
  - This is sufficient for initial screening; HDOCK will refine the pose
- **Key functions**:
  - `generate_peptide_pdb(sequence: str, output_dir: str)` → path to peptide PDB
  - `design_inhibitor_peptides(target_pdb: str, pocket_residues: list, llm)` → list of peptide sequences via LLM

#### Step 1.3: `core/inhibitor_docking.py` — Orchestrate small molecule and peptide docking
- **Small molecule docking**: **AutoDock Vina** (already in conda env as `vina`)
  - Convert receptor PDB → PDBQT (via OpenBabel `obabel receptor.pdb -opdbqt -O receptor.pdbqt`)
  - Convert ligand PDB → PDBQT (same)
  - Define search box using **RNA interface pocket residues** (from protein_agent interface contacts)
  - Run Vina with appropriate exhaustiveness (8-16)
  - Parse top binding poses and energies
- **Peptide docking**: **HDOCK** (already available and working)
  - HDOCK natively supports protein-protein docking — treat peptide as small protein/ligand chain
  - Same receptor PDB can be reused from protein_agent
  - Set `HDOCK_N_MODELS` appropriately for peptide (5-10 models)
- **Key functions**:
  - `dock_small_molecules(receptor_pdbqt, ligands_dir, pocket_center, pocket_size)` → list of results
  - `dock_peptides(receptor_pdb, peptide_pdbs_dir)` → list of results (uses HDOCK)
  - `compute_pocket_from_interface(interface_contacts: dict, protein_pdb: str)` → (center, size) for Vina box
  - `compare_inhibitor_with_rna_pose(inhibitor_pose, rna_poses, cutoff=5.0)` → overlap score

#### Step 1.4: `core/rna_binding_pocket.py` — RNA binding pocket identification
- Use protein_agent's interface contact analysis to define the binding pocket
- `extract_pocket_residues_from_interface(interface_contacts: dict)` → list of residue IDs
- `compute_pocket_centroid(protein_pdb: str, residue_ids: list)` → (cx, cy, cz) for Vina box
- `compute_pocket_size(protein_pdb: str, residue_ids: list, padding=8.0)` → (sx, sy, sz)

### Snapshot Rendering for Inhibitors — Detailed Design

The existing PyMOL renderer (`render_docking_snapshot_pymol` in `docking_visuals.py`) is reused. We add **two new rendering functions** alongside it, plus a **call inside the inhibitor_agent** (matching the pattern in protein_agent).

#### Step 4.5: New rendering functions in `orchestration/utils/docking_visuals.py`

**Function 1: `render_small_molecule_snapshot_pymol(complex_pdb, output_png, title, width, height)`**
- Same core as `render_docking_snapshot_pymol` but PyMOL script is tailored for small molecule display:
  - Protein: `show cartoon, color slate`
  - Small molecule (select `not polymer and not solvent`): `show sticks, color yellow`
  - RNA chain if co-present in the PDB (e.g., from a ternary complex): `show sticks, color orange`
  - Interface highlight: `select interface, polymer within 5 of (not polymer)` → `show surface, color marine, transparency 0.4`

**Function 2: `render_peptide_snapshot_pymol(complex_pdb, output_png, title, width, height)`**
- Similar to RNA snapshot, but:
  - Protein: `show cartoon, color slate`
  - Peptide (select `polymer and not (protein or nucleic)` — or by chain ID heuristic): `show cartoon, color magenta`, `show sticks, color magenta`
  - Interface highlight: `select interface_protein, protein_part within 5 of pep_part` → `color marine, transparency 0.4`

**Function 3: `render_inhibitor_snapshots_for_results(state)`**
- Mirrors `render_docking_snapshots_for_results` but iterates over `inhibitor_small_molecules` and `inhibitor_peptides` state fields:
  ```python
  def render_inhibitor_snapshots_for_results(state: dict) -> dict:
      out_dir = Path(os.getenv("VLAB_DOCKING_SNAPSHOT_DIR", "output_data/docking_snapshots"))

      # Small molecule snapshots
      for r in state.get("inhibitor_small_molecules", []):
          complex_file = r.get("complex_file") or r.get("dock_complex_file")
          if not complex_file: continue
          png = out_dir / f"inhibitor_smallmol_{r.get('name','unknown')}_score{r.get('binding_energy')}.png"
          render_small_molecule_snapshot_pymol(complex_file, str(png), title=...)
          r["snapshot_png"] = str(png)

      # Peptide snapshots
      for r in state.get("inhibitor_peptides", []):
          complex_file = r.get("complex_file") or r.get("dock_complex_file")
          if not complex_file: continue
          png = out_dir / f"inhibitor_peptide_{r.get('sequence','')[:8]}_score{r.get('dock_score')}.png"
          render_peptide_snapshot_pymol(complex_file, str(png), title=...)
          r["snapshot_png"] = str(png)
  ```

#### Step 4.6: Call rendering in inhibitor_agent
At the end of the inhibitor_agent, after docking completes (same pattern as protein_agent line ~2020):
```python
try:
    visual_paths = render_inhibitor_snapshots_for_results({**state, **result})
    if visual_paths:
        result.update(visual_paths)
except Exception as e:
    log.warning("Failed to render inhibitor snapshots: %s", e)
```

This produces PNGs with distinct visual colors (yellow small molecule, magenta peptide) alongside the existing orange-RNA slate-protein scheme, making it immediately obvious which type of binding is shown.

### Verification

1. **Small molecule docking test**: Run Vina with a known RNA-binding compound (e.g., ribavirin or a known capsid binder) against a viral capsid protein — verify output PDBQT has docked poses with reasonable energy (< -6 kcal/mol)
2. **Peptide docking test**: Generate a short peptide (e.g., GRKKRRQRRR — a known RNA-binding peptide) PDB with OpenBabel, dock with HDOCK — verify complex PDB is produced with valid interface contacts
3. **Full pipeline test**: Run with a single iteration, TOPIC_INDEX=0, verify all 7+ agent stages complete including inhibitor analysis in final report
4. **Inhibitor vs RNA comparison**: Verify overlap analysis reports >0 overlap when inhibitor binds at RNA interface
5. **Regression test**: Run with `VLAB_INHIBITOR_ENABLED=0` — verify pipeline completes without inhibitor_agent and produces identical results to current behavior

### Decisions

- **Small molecule source**: PubChem REST API (uses existing `requests` library, no new deps)
- **Peptide structure generation**: OpenBabel `--gen3d` from sequence → extended PDB (HDOCK refines pose during docking). This is pragmatic — true ab initio folding (PEP-FOLD) would need a Java dependency not suitable for HPC. Can be upgraded later.
- **Peptide docking engine**: HDOCK (protein-protein mode) — already installed, tested, and handles the task well
- **Small molecule docking engine**: AutoDock Vina — already in conda env
- **Docking pocket**: Derived from RNA-protein interface contacts from protein_agent (not fixed/assumed)
- **Inhibitor comparison**: RMSD + residue overlap between inhibitor pose and RNA binding pose at the interface

### Further Considerations

1. **Peptide structure quality**: OpenBabel `--gen3d` produces extended conformations, not folded. For better accuracy, consider installing a lightweight peptide structure predictor (e.g., a small ESMFold model or the PEP-FOLD web API) in a future iteration.
2. **Small molecule library scope**: Starting with PubChem search. For production screening, a local ZINC15 or ChEMBL database download would be more systematic but adds ~50GB+ storage. PubChem API is sufficient for proof-of-concept.
3. **Vina scoring**: Vina gives kcal/mol binding energies which are more physically meaningful than HDOCK scores. The skeptic agent should understand this distinction when comparing inhibitor vs RNA binding data.
